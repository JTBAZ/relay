# CP-08a1 — Production read-only lookup evidence

`src/conversational-planning/lookup.ts` implements `createPlanningLookup(prisma)`. Its `lookup` property satisfies the compiler's existing `TrustedLookup`; the returned `loadCreatorTimezone` reads `CreatorPostingGoal` directly and returns null for a missing or invalid IANA zone. It performs database reads only.

The adapter scopes `MediaAsset`, `Post`, `CreativeWorkMember`/parent `CreativeWork`/series, `CreatorPreviewTemplate`, and entitlement queries to the supplied creator. It uses the existing `resolvePostNaming` rules for source title plus a creator-owned presentation/work overlay. Post media IDs are included only after resolving to creator-owned `MediaAsset` rows. The lookup does not return storage keys, URLs, bytes, template credentials, or platform credential details. The schema has no filename column for `MediaAsset`, so the compiler's optional `filename` is deliberately null; this adapter does not relabel `currentRole` as a filename.

Selection and relation expansion are bounded. More than 32 requested IDs or more than 128 linked post candidates throws into the compiler's existing fail-closed source-scope handling. Name lookup uses exact creator/name filtering with a four-row cap, enough to preserve duplicate detection. It does not select a latest template or truncate source relations. The result keeps all creator-owned work/series identities so the compiler can clarify genuine ambiguity. Template config is returned only to the existing trusted compiler, which parses it before use; model context still receives only bounded template identity/name.

Destination readiness is projected from `listConnectedPlatforms`: only `destination` and `readiness` leave that service. X and DeviantArt remain `needs_extension`; Patreon and Bluesky depend on the service's existing readiness reads.

`hasEffectiveAutopostReadOnly` mirrors `requireCreatorPlanAtLeast(..., autopost)` gate precedence without importing its mutating resolver. A sufficient unexpired snapshot is accepted. If an unexpired `operator_grant` or `pilot` snapshot is below Autopost, it remains authoritative. Otherwise the helper checks the account linked to the exact creator and its newest active/trialing creator-scope subscription; an expired/missing/lower Stripe snapshot can therefore resolve from the subscription mirror. It never reads the legacy posting-assistant flag, calls Stripe, upserts, or deletes. Missing account/subscription and unsupported/lower plans fail closed.

Remaining architecture boundary: this slice does not provide the `ContextLoader`, deterministic source fingerprint, repository revalidation transaction, or edit-handle map. CP-08a2 owns those. The existing `SourceMediaRow.filename` has no corresponding field on `MediaAsset`; it remains null until an architect-approved metadata mapping exists. Current source metadata exposed here is limited to processing state, ingest origin, post links, current role-independent MIME type, and draft reservation pointer. No schema or source-contract widening was made.

Direct strict TypeScript checking of `tests/conversational-planning/lookup.test.ts` passed. `npm run build` passed, including Prisma Client generation, backend TypeScript compilation, and build asset copying.
