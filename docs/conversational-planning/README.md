## Architecture gates and completion evidence

The parent architect reviews CP-01 isolation; CP-03 atom mapping; CP-04 typed contract; CP-06 compiler grounding; CP-07 migration/idempotency; CP-08 API transactions; CP-09 authority mapping; CP-10 browser journey; CP-11 media ownership; CP-12 publication-evidence definition; CP-13 timing/migration; CP-14 evaluation protocol; CP-16 runtime measurement; and CP-15 pilot evidence. ```text
```text
Ticket / status:
Owned files changed (and why any approved seam was touched):
Behavior demonstrated, including one negative case:
Focused tests/build/browser evidence (command + result; skipped prerequisites):
Existing authority and idempotency/creator-scope evidence:
Risks or unresolved product questions:

Next unblocked ticket:
```

The pilot gate requires synthetic desktop and mobile review of the whole journey, duplicate/restart recovery, creator isolation, manual-edit preservation, missing links/media/templates, mixed destination outcomes, delayed publication, cancellation, rescheduling and DST. Plan confirmation cannot be counted as posting, composer fill cannot be counted as publication, and no engagement reminder can materialize from an unverified handoff unless the creator explicitly confirms publication through a reviewed flow. The flag remains off by default until a human pilot owner approves the evidence.
