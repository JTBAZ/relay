`tests/conversational-planning/api-postgres.integration.test.ts` mounts the accepted conversational-planning prefix parser and controller in a minimal Express application. The suite skips when `CONVERSATIONAL_PLAN_TEST_DATABASE_URL` is absent. Fixture rows are nonce-scoped inside that fresh database. Root executed the reviewed fixed CP-08 harness against a fresh nonce-owned disposable database, applying migrations only there. The race only demonstrates duplicate storage/revision safety; concurrent model-spend exactly-once behavior is not claimed.
