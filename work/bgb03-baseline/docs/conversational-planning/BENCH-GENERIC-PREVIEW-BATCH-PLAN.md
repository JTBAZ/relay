## Creator flow

A request such as “Select my sketches and prepare previews for X and DeviantArt” records one selection and an ordered set of destinations. The creator chooses the existing Square teaser template and either existing titles or one quoted literal copy choice. One confirmed Previewizer JPEG per selected artwork can serve both destinations when its source media, source fingerprint, template and export hash still match. The bench then shows a matrix of artwork × destinations. Each cell names its destination and state: needs preview, ready to review, confirmed draft, skipped, or blocked with a reason. The creator can skip or restore an unconfirmed cell; excluded artwork stays excluded under the existing selection rules. A later chat turn or refreshed page reconstructs the same active matrix and keeps prior confirmations visible.

For each ready cell, **Review draft** shows the exact pinned JPEG, source, destination-specific copy and field differences. X uses its `postText` and 280-character limit. DeviantArt uses its title, frozen source description/body, normalized tags and 200-character title limit. **Confirm draft** creates only that cell's unscheduled mock draft. Each confirmed cell can then use its existing separate **Review schedule → Confirm schedule** and **Review handoff → Confirm and open** controls. A date/time or handoff for one destination is never inferred for another. The extension opens the saved package for manual review and publication; opening or filling is not publication evidence.

The matrix is a grouped worklist, not a bulk transaction. Confirming one cell does not confirm its neighbors. Existing routes keep a single pending draft review, so the UI prepares one review token at a time, confirms or cancels it, refreshes the matrix, and then permits the next cell. No pre-generated token bundle, “Confirm all” button, automatic retry, rollback promise, or model call per target. A failed or stale cell retains its place with a review-again action. Already confirmed cells and their receipts remain intact. The creator can stop after any cell and resume while the temporary session exists.
