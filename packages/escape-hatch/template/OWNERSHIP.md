# Ownership

This generated Escape Hatch site kit is intended to be **creator-owned**.

- You own the application source, data, domain, infrastructure credentials, and billing accounts you configure.
- Supabase Auth/Postgres (EH-030), when enabled, runs in **your** project — Relay does not hold those credentials.
- Relay optional services (if later enabled) are disclosed, revocable, and replaceable; they are not required to build or soft-preview this chassis.
- This kit is **`productionSafe: false`**: identity path is available when configured; soft persona remains for local preview; no hard paywall; no signed private media delivery claim (EH-033).

Bootstrap and key rotation: `scripts/bootstrap-identity.md`. See `escape-hatch.manifest.json` for chassis/schema versions and adapter states.
